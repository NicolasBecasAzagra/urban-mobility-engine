# Data Directory

**⚠️ IMPORTANT:** The large data directories are NOT versioned in Git (see `.gitignore`).

## Structure

```
data/
├── raw/              # CSVs downloaded from Madrid (large files)
├── processed/        # Output of the Rust engine
└── samples/          # Reduced samples for local testing
```

## Input Data (data/raw/)

Download the datasets from:
- **Portal:** https://datos.madrid.es/portal/site/egob/
- **Dataset:** "Tráfico: Histórico de datos del tráfico desde 2013" (Traffic: historical traffic data since 2013)
- **Format:** compressed CSV (.zip), one per month

**Example:**
```bash
# Download and save here:
data/raw/madrid_trafico_01_2026.csv  # ~500 MB uncompressed
```

## Processed Data (data/processed/)

Output generated by the engine:
```bash
cargo run -- --input data/raw/madrid_trafico_01_2026.csv \
             --output data/processed/
```

## Tests

For tests, use small samples in `tests/fixtures/` (these ARE versioned):
```bash
# Create a 1000-line sample:
head -n 1000 data/raw/madrid_trafico_01_2026.csv > tests/fixtures/madrid_sample_1000.csv
```
